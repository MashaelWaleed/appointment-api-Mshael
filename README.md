# Appointment Booking API - Developed by Haneen

## الوصف

واجهة برمجة تطبيقات (API) مصغرة لحجز المواعيد. تم تصميمها لمنع الحجز المزدوج (Double Booking) عند وصول طلبات متزامنة، مع دعم التحديثات اللحظية والإلغاء.

## التقنيات المستخدمة

- **الخلفية:** Node.js, Express.js, TypeScript
- **قاعدة البيانات:** PostgreSQL, Prisma ORM
- **التحديثات اللحظية:** Socket.IO
- **التوثيق:** Swagger (OpenAPI 3.0)

## حل تحدي الـ Concurrency (Race Conditions)

لمنع الحجز المزدوج عند وصول طلبين في نفس اللحظة الزمنية، تم استخدام **Prisma Transactions** مع مستوى عزل `Serializable`. هذا يضمن وضع قفل (Lock) مؤقت يمنع القراءة والكتابة المتزامنة لنفس الوقت، مما يرد الطلب المتأخر بخطأ `409 Conflict`.

## خطوات التشغيل

1. تثبيت المكتبات: `npm install`
2. إعداد قاعدة البيانات في ملف `.env` (استخدمت Neon السحابية لسرعة الإنجاز).
3. تطبيق جداول قاعدة البيانات: `npx prisma migrate dev`
4. تشغيل الخادم: `npm run dev`

- **واجهة التوثيق (Swagger):** متاح على `http://localhost:3000/api-docs`
